World Clock in Java

About the Project
This project consists of an application developed in Java with the goal of working with regions around the world and, eventually, displaying the local time in each region.

The project was developed as part of my Java programming studies, focusing on hands-on practice and learning.

Features
- Creation of a list of 10 major world regions.
- Identification of the time zones for each region.
- Display of the local time in each region.

Technologies Used

1. Java
2. ArrayList
3. "Locale","TimeFormat", "DateTime" and "ZoneId".
 
How to Run
Make sure Java is installed.
Download or clone this repository.
Open the project in a Java-compatible IDE.
Run the main class of the program.
What I Learned
The project aims to practice Java concepts, collections, code organization, and time zone handling.
